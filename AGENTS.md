# ONEFIND — instruções para Codex

Projeto React 19 + TypeScript + Vite + Tailwind CSS + Supabase.

## Escopo
- Priorize qualidade visual, acessibilidade, responsividade e performance.
- Use as skills de design instaladas no ambiente quando disponíveis; não presuma que foram instaladas só por existir este arquivo.
- Consulte referências de Figma apenas após autorização e autenticação.
- Teste alterações de interface usando Playwright MCP quando estiver conectado, em 320px, 390px, 430px e desktop.
- Execute npm run lint, npm test e npm run build antes de propor merge.
- Preserve fluxos de autenticação, agendamento, financeiro, assinatura, trial e RLS.
- Não altere dados reais nem faça deploy de produção sem aprovação explícita.
- Evite dependências de runtime para tarefas exclusivas de design.

## Preparação
Siga docs/design-tooling-setup.md para instalar as skills e conectar Figma/Playwright MCP ao Codex. Verifique a procedência e os comandos de cada projeto antes de executá-los.
